Creative Music Television: automated content pipeline

A hands-off publishing system I designed and run. It takes a library of short-form music, DJ and AI clips, follows a content calendar, and publishes Instagram Reels and YouTube Shorts on schedule with no one touching it. It recovers from errors and keeps a record of everything it posts.

System 1

End-to-end publishing flow

A scheduled GitHub Actions job wakes up every hour. It reads the content calendar, works out which posts are due in Central time, and publishes up to a set number per run so a backlog never floods the feed. Each finished post is saved back to the repo, so the system never posts the same clip twice.

System 2

Reliable Instagram Reels publishing

Instagram processes video in the background and sometimes reports an error before it finishes. The publisher waits through that instead of giving up, and only fails a post after repeated errors. A failed post is retried on the next hourly run.

System 3

Cross-posting to YouTube Shorts

Rows marked for YouTube are reposted as Shorts. The uploader swaps its saved login for a fresh access token each run, downloads the clip from where it's hosted, turns the Instagram caption into a YouTube title, and uploads in one step. A separate setup script handles the one-time Google login.
