Orbit

AI outreach platform with an AI agent that handles replies

Software used by several separate organizations, each seeing only its own data. Orbit scrapes Instagram leads and personalizes and queues DMs, then runs follow-ups. When someone replies, Claude reads it and drafts or sends an answer. Every week, a model rewrites the outreach copy based on what got responses. The sending queue checks for duplicates in four separate ways, retries with growing delays, and cancels stale messages after 48 hours.

The Captain's HQ

A Claude console that knows the business

A private console that opens with the day's most important task, plus posting status, email sequences, projects and the outreach pipeline. The built-in Claude chat streams its answers and keeps the full business background on hand without resending it each time, using prompt caching. It can look up live data and has hourly and monthly usage limits. Every morning at 6:00 a scheduled job rebuilds that background, runs the tests, deploys, and shows a warning on the console if the data is out of date.

Grant Radar

Grant matching you can explain

Scores about 32 music, media and arts grants against the company's profile across 8 weighted categories. Each match shows why it scored the way it did, and each grant comes with a starting draft of the application. An AI step that searches the web for new grants is planned next.

CMW Autopost

Automated content publishing

A hands-off publishing system I designed and run. It takes a library of short-form music, DJ and AI clips, follows a content calendar, and publishes Instagram Reels and YouTube Shorts on schedule with no one touching it. It recovers from errors and keeps a record of everything it posts.

End-to-end publishing flow

A scheduled GitHub Actions job wakes up every hour. It reads the content calendar, works out which posts are due in Central time, and publishes up to a set number per run so a backlog never floods the feed. Each finished post is saved back to the repo, so the system never posts the same clip twice.

Reliable Instagram Reels publishing

Instagram processes video in the background and sometimes reports an error before it finishes. The publisher waits through that instead of giving up, and only fails a post after repeated errors. A failed post is retried on the next hourly run.

Cross-posting to YouTube Shorts

Rows marked for YouTube are reposted as Shorts. The uploader swaps its saved login for a fresh access token each run, downloads the clip from where it's hosted, turns the Instagram caption into a YouTube title, and uploads in one step. A separate setup script handles the one-time Google login.
